## Consolidated findings

The `REGRESSION_CONFIRMED` category records a historical regression, not a defect still present: `apps/desktop/src/main/pi-binary-resolution.ts` now restores the explicitly selected Pi fallback while retaining FineCode as the default. The test at `apps/desktop/src/main/pi-binary-resolution.test.ts` asserts the explicit Pi and default FineCode results on POSIX and Windows. The remaining runtime differences are intentional FineCode improvements or equivalent fixture changes; no uncorrected production regression or missing behavior was demonstrated. The historical tree does not require restoring behavior that the current product deliberately changed (notably FineCode default engine, supported Codex model catalog, and audit provenance constraints). This PR makes no production change.

The two Cloudflare Access tests already present in the original worktree are useful regression coverage for (1) unauthenticated custom gateway plus service-token headers and (2) stored Access token without an AI Gateway key. Existing resolver paths support both. They remain untouched in the original worktree and were not cherry-picked into this review branch.
