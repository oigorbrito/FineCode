# Contributing to FineCode

FineCode is maintained as a solo project. The repository no longer automatically closes issues or pull requests based on contributor approval. Submissions are welcome, but do not guarantee review or acceptance; the maintainer considers them as time allows.

Upstream Pi issues, pull requests, releases, and code may be monitored as references; no code or change is incorporated into FineCode automatically. The maintainer decides what to port, adapt, accept, or decline.

## Code changes

For code changes, read [AGENTS.md](AGENTS.md) first and follow its development and validation rules. Keep changes focused and explain the problem they solve and how you tested them.

For security-sensitive reports, see [SECURITY.md](SECURITY.md). Do not post vulnerability details publicly.
