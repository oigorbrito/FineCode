# Contribuindo com o FineCode

O FineCode é mantido como um projeto solo. O repositório não fecha automaticamente issues nem pull requests com base em uma lista de colaboradores aprovados. Contribuições são bem-vindas, mas o envio não garante revisão nem aceitação; o mantenedor as avalia conforme sua disponibilidade.

Issues, pull requests, versões e código do Pi upstream podem ser acompanhados como referência; nenhum código ou alteração é incorporado automaticamente ao FineCode. O mantenedor decide o que portar, adaptar, aceitar ou rejeitar.

## Alterações no código

Para alterações no código, leia primeiro o [AGENTS.md](AGENTS.md) e siga as regras de desenvolvimento e validação. Mantenha as alterações focadas e explique o problema que resolvem e como foram testadas.

Para relatos sensíveis de segurança, consulte [SECURITY.pt-BR.md](SECURITY.pt-BR.md). Não publique detalhes de vulnerabilidades.
